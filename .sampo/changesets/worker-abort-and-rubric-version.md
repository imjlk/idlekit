The local execution backend checks the abort signal again after each runner returns, so a batch cancelled while a synchronous runner was running reports that task as cancelled instead of ok and is never a full distribution. Judge rubric rules may pin `metricVersion`: a pinned rule reads only that version of its metric and is rejected as a missing ref when the artifact carries another version, while an unpinned rule (every existing rubric) still reads any version and each diagnostic now reports the version it read. The Jev projection uses the same reading selection.
